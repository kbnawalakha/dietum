# Claude Instructions

Read `AGENTS.md` first and follow the shared repository rules.

## Review Approach

- Do not invent a separate architecture.
- Prefer reviewing requirements, implementation plans, diffs, and missing states.
- Do not duplicate work assigned to Codex.
- Produce concrete file-level recommendations.
- Separate blocking issues from optional improvements.
- Do not approve a task without checking acceptance criteria.
- Do not rewrite an entire feature when a focused fix is sufficient.
