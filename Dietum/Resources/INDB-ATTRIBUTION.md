# Indian Nutrient Databank Attribution

The bundled `indb_recipes.json` catalog is derived from the Indian Nutrient
Databank (INDB), published by Anuvaad.

Source: https://www.anuvaad.org.in/indian-nutrient-databank/

INDB provides open-access nutrition values for common Indian recipes and foods.
The catalog is stored as per-100 g values and is used for ingredient-list
matching before the app falls back to USDA FoodData Central.

The bundled export was generated from `Anuvaad_INDB_2024.11.xlsx` on 2026-11-18.
